3. How to perform the test

A simple repeatable procedure. Select the actual pipe diameter in the test readings section.

  1. Confirm the pipe is full of water, flow direction is correct, and there is no bypass or leakage.
  2. With water flow stopped, note the previous cumulative Modbus totalizer value (L).
  3. Choose the interval you want to test. Start the timer as you begin collecting water.
  4. Collect the water in a calibrated container. Record the actual collected litres and elapsed time.
  5. During the same collection interval, record the meter-reported flow rate at regular intervals (for example every 5–10 seconds), in L/min. Calculate the average of those readings and enter it above.
  6. Stop the flow and note the new cumulative totalizer value (L).
  7. Enter all values above and calculate. Repeat at low, medium and higher flow rates within the meter's rated range.

If the meter totalizer uses multiple Modbus registers, combine them using the manufacturer's documented data type, word order and scaling. Enter the resulting cumulative volume in litres.
